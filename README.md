# AiGhost — Investor & Technology Overview

**Local-first AI direction · privacy-first social software · opt-in home-node infrastructure**

*Public technology overview only. The core application and development source code remain private.*

## At a glance

AiGhost is an evolving software ecosystem with three connected tracks:

1. **Ghost** — a privacy-first social and messaging product.
2. **Ghost Home Node** — a consent-based, same-account store-and-forward concept for enrolled devices.
3. **Neuroplasma Optical Fabric** — an isolated software research model exploring a possible hybrid optical/electronic network architecture.

The opportunity is to explore a user-controlled, local-first product ecosystem while validating the technical, security, operational, and hardware requirements step by step.

## Why it may matter

AiGhost explores a product direction in which useful AI and network capabilities are closer to the user and their devices, with explicit consent and bounded participation rather than silently treating personal devices as shared infrastructure.

Neuroplasma makes parts of that research direction testable in software. It keeps optical transport, active optical processing, temporary signal delay, and persistent memory as separate engineering concepts. Ordinary fibre and passive mirrors do not behave like general-purpose computer memory or software processors.

## Evidence and limitations

The Neuroplasma engineering note dated 30 October 2026 describes an isolated five-role software loopback. It explicitly states that no physical transceiver, fibre, NIC, or live optical transport was used. Key provisioning, secure distribution, rotation, and recovery are not yet implemented.

The reviewed development snapshot was dated 31 October 2026. Three Vercel status contexts were reported as failing with **“Account is blocked.”** This overview therefore does not claim a verified current production deployment.

Test counts recorded in the engineering note are 49 Neuroplasma fabric tests, 13 guardian-policy tests, and one end-to-end integration test (63 focused tests passing together), plus a wider documented 119-test regression selection. These recorded counts were not independently rerun for this publication.
